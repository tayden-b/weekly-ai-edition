# A7: Adapter — benchmark publishers

**Wave:** 2 · **Depends on:** C5

## Context

PLAN §5.1: Performance page — publisher data with stable endpoints/CSV: LMArena leaderboard, Artificial Analysis (public JSON), Hugging Face Open LLM Leaderboard API, SWE-bench, ARC Prize, Epoch AI datasets; arXiv API for papers from the lab orgs. **ToS check per source** is explicitly called out — anything doubtful ships as a link, not data (§9 risk note).

## Scope

- `packages/pipeline/src/sources/benchmarks.ts` (+ `arxiv.ts` for the arXiv part — one file per adapter rule), implementing the C5 interface.
- For each publisher: find the stable data endpoint (public JSON/CSV/API). Where none exists or ToS is doubtful, record it and emit the source as a headline+link item (e.g. leaderboard URL + observed change summary) rather than scraped data — document each decision in the licence note.
- arXiv: API query for papers from the lab orgs in-window; arXiv id as `source_ids`.
- Licence notes per publisher — the most scrutinized file in this item.
- Fixtures + harness tests.

## Out of scope

- Rank deltas/score interpretation beyond storing the publisher's reported values (P5/extraction).

## Interfaces

- C5 `RawItem`; `config/sources.yaml` incl. a `mode: data|link` flag per benchmark source.

## Proof

- Per-publisher ToS findings table in the PR (endpoint, licence posture, data-vs-link decision).
- Fixture replay yields RawItems per enabled source.

## Acceptance

- Every §5.1 benchmark publisher represented with an explicit data-vs-link decision + licence note.
- arXiv adapter covers lab-org papers in-window.
- Where data is stored, it's the publisher's own numbers with URL + timestamp.
- Deterministic fixtures/tests; graceful failure.
- `pnpm check` green.
