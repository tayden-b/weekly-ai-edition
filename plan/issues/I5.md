# I5: A11y + perf budgets enforced in CI

**Wave:** 4 · **Depends on:** V1, V2

## Context

DESIGN §5: WCAG AA contrast (`--ink-3` never under 14px), deck fully keyboard/SR operable (`role="region"`, `aria-valuenow`), Lighthouse mobile ≥ 95 performance / 100 accessibility on the deck, self-hosted subset fonts `font-display: swap`, cover ≤180KB AVIF, no client JS on the front page except the allowed islands. PLAN §7.2 adds Playwright smoke + Lighthouse budget to required CI — this item makes them real gates.

## Scope

- Playwright smoke job in `.github/workflows/ci.yml` (separate job from `ci`, e.g. `playwright`, unless folding in is clearly better — document the choice): deck + front page render, swipe/keyboard paths exercised on the fixture edition.
- Lighthouse CI budget: mobile ≥95 performance / 100 accessibility on the deck — enforced in CI (`@lhci/cli` or equivalent; budgets file committed).
- axe-core (or equivalent) automated a11y scan over the main routes in the Playwright job — zero critical/serious violations.
- Asset budgets: cover ≤180KB AVIF, fonts self-hosted + subset + `font-display: swap`, no unexpected client JS on front page — enforced by the budgets/tests.

## Out of scope

- Fixing deep design drift (I4's domain — file `plan-defect` if a failure is really a design bug).

## Interfaces

- `ci.yml` extension; fixture edition from I1 (or C2 fixture) served by the built app in CI.

## Proof

- CI run on the PR shows the new jobs green; a seeded violation (temporarily) demonstrates failure — show it in the PR history/notes.

## Acceptance

- Playwright smoke suite runs in CI against the built app covering deck + front page + keyboard nav.
- Lighthouse budgets (perf ≥95, a11y 100, mobile deck) enforced in CI.
- Automated a11y scan finds zero critical/serious violations on main routes.
- Asset budgets enforced (cover ≤180KB, font-display: swap, client-JS allowlist).
- `pnpm check` green.
