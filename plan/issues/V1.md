# V1: Mobile deck renderer (swipe cards)

**Wave:** 2 · **Depends on:** C2, C4

## Context

DESIGN §2.1 (the deck — full-viewport swipe cards, Stories-like but no auto-advance), §3 (per-page rules), §1.4 (motion: 240ms translate-only), §5 (a11y: deck fully operable by keyboard + screen reader). Renders a C2-conformant edition JSON.

## Scope

- `/{issue}` route serving < 768px viewports as the deck: one full-viewport card per template page in fixed order.
- Card anatomy per §2.1: progress segments (11 hairlines, filled=read), masthead row (`THE WEEKLY AI EDITION` + `№ N · date range`), kicker (page name, accent on cover only), title, item list (headline / one-liner / source line, optional italic take after em-dash), footer (source count · page n/11).
- Horizontal swipe + tap-right/tap-left navigation; vertical scroll inside a card when content overflows; no auto-advance.
- Motion: 240ms `cubic-bezier(0.2,0,0,1)` translate only; progress fill 200ms linear; `prefers-reduced-motion` → instant cut.
- Back-page card ends with the mono row `Hand this week to your agent → /{issue}.md`.
- Wire the fixture edition (2026-w44) in so the deck renders real data.

## Out of scope

- Desktop layout (V2), per-page routes/OG images (V3), archive (V4).

## Interfaces

- Consumes `Edition` from `@weekly/schema` + primitives from `@weekly/ui` (`Deck`, `DeckCard`, `ProgressSegments`, `Item`…). No inline tokens.

## Proof

- Screenshots of every card type at 390×844 on the Vercel preview, attached to the PR.
- Keyboard-only navigation and a screen-reader pass (roles/labels) demonstrated.
- `prefers-reduced-motion` emulation shows instant transitions.

## Acceptance

- `/{issue}` renders the fixture edition as full-viewport swipeable cards in fixed template order at 390×844.
- Card anatomy matches DESIGN §2.1 exactly: progress segments, masthead, kicker (accent on cover only), item lists, footer.
- Swipe + tap zones work; card-internal vertical scroll works; no auto-advance.
- Motion spec honoured (240ms translate-only; reduced-motion cut).
- Cards are `role="region"` with page names; progress uses `aria-valuenow`; fully keyboard operable.
- `pnpm check` green.
