# A2: Adapter — HN Algolia

**Wave:** 2 · **Depends on:** C5

## Context

PLAN §5.1: Launches (front page + "Show HN", AI-filtered by taxonomy terms) and Discourse (comment-count-weighted). HN Algolia API is free, no key, stable endpoints (`hn.algolia.com/api/v1/search`, `search_by_date`).

## Scope

- `packages/pipeline/src/sources/hn-algolia.ts` implementing the C5 adapter interface.
- Queries: front-page AI items + `Show HN` AI-filtered by taxonomy terms derived from the taxonomy in C3 (document the term list in `config/sources.yaml` or a config key).
- Capture `objectID` as `source_ids`, plus engagement fields (points, num_comments) into the RawItem engagement slots — Discourse and rank need them.
- Licence note (HN API terms, rate-limit courtesy), fixture + harness test.

## Out of scope

- The taxonomy itself (C3); the comment-weighted ranking (P2).

## Interfaces

- C5 `RawItem` contract incl. engagement fields; `config/sources.yaml`.

## Proof

- Fixture replay yields valid RawItems with objectID + engagement captured.
- Live smoke run pasted in PR.

## Acceptance

- Adapter implements the C5 interface; registered in `config/sources.yaml`.
- Both front-page and Show HN covered; AI filter terms documented + configurable.
- `objectID`, points, comment count captured per item.
- Licence/rate-limit note present; ≤300-char excerpts; no bodies.
- Deterministic fixture test, no network in tests; failure degrades gracefully.
- `pnpm check` green.
