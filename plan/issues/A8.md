# A8: Adapter — market data (weekly close)

**Wave:** 2 · **Depends on:** C5

## Context

PLAN §5.1: Markets page — a licensed market-data API with a free tier and redistribution-permitted *weekly close* data; candidates in priority order: Stooq CSV (no key), Alpha Vantage, Finnhub, Twelve Data. Basket fixed in `config/markets.json` (C5 seeds it). §9: licence check is the risk — the note matters.

## Scope

- `packages/pipeline/src/sources/markets.ts` implementing the C5 interface, emitting one RawItem per ticker per week (close, week-over-week delta) or one basket item — choose the shape that maps cleanest to the schema's markets page and document it.
- Provider selection: try Stooq CSV first (no key); fall back through the candidate list only if Stooq fails. Provider choice lives in `config/markets.json`/`config/sources.yaml`, not code.
- Licence note: redistribution posture for weekly-close aggregates — be explicit (this is the source most likely to ship as links-only if the licence is doubtful).
- Fixture + harness tests.

## Out of scope

- Chart rendering (V2's LineChart); intraday data (weekly close only).

## Interfaces

- C5 `RawItem`; `config/markets.json` basket.

## Proof

- Fixture replay yields the full basket with weekly closes + deltas.
- Licence finding documented per candidate provider; chosen provider justified in PR.

## Acceptance

- Adapter implements the C5 interface; basket read from `config/markets.json`.
- Weekly close + week-over-week delta per ticker captured as numbers destined for `evidence` spans.
- Licence note per candidate provider; redistribution posture stated.
- Deterministic fixtures/tests; provider failure degrades page only.
- `pnpm check` green.
