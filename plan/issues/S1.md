# S1: Ship v1 — first real edition, publish, flip public, V1-REPORT

**Wave:** 5 · **Depends on:** I1, I2, I3, I4, I5

## Context

PLAN §7.4 wave 5 + §7.5 definition of done. The last session. Everything before you built the machine; you run it for real.

## Scope

- Produce the **first real edition from live sources** for the current week: run the full pipeline (deterministic stages via `pnpm edition:build`; intelligence stages performed by you through the session `llm()` seam per §8 + STYLE.md + versioned prompts), emit `editions/<week>.json`, pass schema + provenance gates, open and land the edition PR.
- Publish: production URL live serving the real edition in both renderers.
- Flip the repo **public** (`gh repo edit --visibility public`).
- Run the **agent-twin test**: a fresh Devin session (child session) given only the issue URL must summarize the week correctly — record what it produced and whether it matched the edition.
- Write `plan/V1-REPORT.md`: what shipped, what degraded (failed/degraded sources), costs (sessions, ACU if visible), known gaps, first 5 recommended follow-ups.
- Comment on the `v1-complete` issue **starting with `@tayden-b`** followed by the report's summary (this is the notification — GitHub emails him).

## Out of scope

- Anything post-v1: custom domain, email subscription, MCP endpoint, cover-image generation (T3 deferred), taste-level design changes.

## Interfaces

- `pnpm edition:build` (I1); weekly automation (I2); production deploy (I3); schema/provenance gates (C2/P7).

## Proof

- Live production URL serving a real edition built from live verified sources.
- Agent-twin test transcript/verdict documented in `plan/V1-REPORT.md`.
- `@tayden-b` comment posted on `v1-complete`.
