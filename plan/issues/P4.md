# P4: Classifier + company tagging (≥90% on the C3 set)

**Wave:** 3 · **Depends on:** C3, P1

## Context

PLAN §5.2: `classify` — LLM with the schema taxonomy, temperature 0, structured output, confidence; < 0.7 → `unsorted`. §8: classification is performed BY the Devin session (no external LLM API) following the versioned prompt in `packages/pipeline/prompts/`; `llm()` is a seam, not an SDK call. §5.3: company tags must come from `config/companies.yaml`; unknown companies → `unsorted`, never auto-added.

## Scope

- `packages/pipeline/src/stages/classify.ts`: the deterministic shell of the LLM stage — takes ranked clusters → produces `{page, confidence, company_slugs[]}` slots; the actual judgement call goes through the `llm()` seam reading `prompts/classify.prompt.md`.
- `llm()` seam: a minimal typed interface (e.g. `classify(items) → ClassifiedItem[]`) with two implementations: `session` (the running Devin session fills a batch file — document the hand-off format: stage writes `classification.request.json`, session writes `classification.response.json`) and a deterministic `replay` implementation for tests/CI reading recorded responses.
- Company tagging: slugs validated against `config/companies.yaml`; unknown names → item falls to `unsorted` (per §5.3 — never mint new companies).
- Accuracy harness: run the C3 labelled set through the classify path (you, the session, produce the labels via the seam) and report measured accuracy in the PR — must be ≥ 90%.
- Confidence < 0.7 → `unsorted` enforced in code.

## Out of scope

- Drafting prose (P6); evidence spans (P5); prompt redesign beyond what ≥90% needs.

## Interfaces

- `llm()` seam signature documented for P5/P6 reuse; `prompts/classify.prompt.md` versioned.
- Output type consumed by `emit`; `unsorted` items must never reach an edition page.

## Proof

- Measured accuracy ≥ 90% on the C3 labelled set — numbers + confusion notes in the PR.
- A replayed response file lets CI run the accuracy harness deterministically.

## Acceptance

- Classify stage emits page label + confidence + company slugs via the `llm()` seam.
- Confidence < 0.7 → `unsorted`; unknown companies → `unsorted` (no auto-add) — tested.
- ≥ 90% measured accuracy on the C3 labelled set, recorded in the PR.
- Replay implementation makes classification deterministic in tests/CI.
- `prompts/classify.prompt.md` versioned and referenced by the stage.
- `pnpm check` green.
