# A3: Adapter — newsroom RSS set

**Wave:** 2 · **Depends on:** C5

## Context

PLAN §5.1: Launches + Deals + Discourse secondary sources — TechCrunch AI, The Verge AI, Ars Technica AI, MIT Technology Review, Reuters tech, Bloomberg tech — headline+link only (Bloomberg/Reuters may be partial feeds; record what's actually available).

## Scope

- `packages/pipeline/src/sources/newsroom-rss.ts` implementing the C5 adapter interface across the newsroom RSS set.
- `config/sources.yaml`: one entry per newsroom with feed URL + licence note (many newsroom feeds permit headline+link aggregation; note explicitly that we store headline/link/excerpt ≤300 chars only, never bodies).
- Recorded fixtures per feed + harness tests.
- Opinion/section tagging where the feed exposes it (Discourse needs opinion-ish items flagged — document the mechanism, e.g. feed category).

## Out of scope

- Deduping against other sources (P1); deciding discourse vs launch placement (P4).

## Interfaces

- C5 `RawItem`; `config/sources.yaml`.

## Proof

- Fixture replay yields RawItems for each newsroom feed.
- Per-feed licence notes written; live smoke run in PR.

## Acceptance

- Adapter covers the §5.1 newsroom set (or documents which feeds are unavailable/blocked and why).
- Headline+link+excerpt only — never article bodies.
- Fixtures + harness tests deterministic, no network.
- Failure of one feed degrades its page, not the run.
- `pnpm check` green.
