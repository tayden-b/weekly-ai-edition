# C5: Source-adapter interface + RawItem type + adapter test harness + config

**Wave:** 1 · **Depends on:** B0

## Context

PLAN §5.1 is the spine: every item in an edition traces to a record fetched from a publisher we trust, by code, with a URL and a timestamp. This item defines the contract every A-adapter implements and the config files that make sources data, not code. Also the provenance groundwork for §5.3.

## Scope

- `RawItem` type in `packages/pipeline` (or `@weekly/pipeline`): `headline`, `canonical_url`, `publisher`, `published_at`, `fetched_at`, `excerpt` (≤ 300 chars, enforced), `source_ids` (source-specific ids, e.g. HN objectID, EDGAR accession), optional engagement fields (hn_comments, hn_points, reddit_score).
- Adapter interface: `fetch(window: {from, to}) → RawItem[]` + `health() → {ok, detail}`. Pure TypeScript, injectable fetcher for tests.
- Adapter test harness: run an adapter's `normalize/map` functions against its recorded fixture (`__fixtures__/<name>.json`) deterministically — NO network in tests. Convention every A-item must follow, enforced by the harness helpers.
- `config/sources.yaml`: encode the §5.1 source table — every source with id, page(s) it feeds, endpoint/feed URL, adapter id, licence note, rate limit, enabled flag. `config/companies.yaml`: seed company registry (slug, name, aliases, domain, ticker) for the AI-basket names + the major labs.
- `config/markets.json`: the fixed Markets basket (NVDA, MSFT, GOOGL, META, AMZN, AMD, TSM + 2–3 pure plays — pick and justify).
- A documented UA convention: `weekly-ai-edition/<ver> (+<site url>)` identifying the project with a contact URL (§5.1 rule).
- A trivial reference adapter (e.g. a `noop` or fixture-replay adapter) proving the interface end-to-end in tests.

## Out of scope

- Real adapters (A1–A10); normalize/dedupe internals (P1); storage layout (P3).

## Interfaces

- `RawItem` is THE boundary between adapters and stages — coordinate field names with C2's `EditionSource` so mapping is mechanical.
- `config/sources.yaml` schema documented in-file; A-items only add entries, never reshape it.
- Harness API: e.g. `runAdapterFixture(adapter, fixturePath)` asserting every emitted item is a valid `RawItem`.

## Proof

- Harness runs the reference adapter against a fixture in `pnpm test` — green, no network.
- `config/sources.yaml` contains every primary source listed in §5.1 for its page, each with a licence note.
- `RawItem.excerpt` length cap enforced by a test (a >300-char excerpt fails).

## Acceptance

- `RawItem` type + `fetch(window)`/`health()` adapter interface exported from `@weekly/pipeline`.
- Deterministic adapter test harness (fixtures, no network) shipped and used by a reference adapter.
- `config/sources.yaml` encodes the full §5.1 source table with licence notes; `config/companies.yaml` + `config/markets.json` exist.
- UA convention documented and constant exported for adapters.
- `excerpt` ≤ 300 chars enforced by code + test.
- `pnpm check` green.
