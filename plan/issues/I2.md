# I2: Weekly Edition automation (cron → PR → Sunday auto-publish)

**Wave:** 4 · **Depends on:** I1

## Context

PLAN §5.2 runs: weekly Saturday 06:00 ET full build → PR; Sunday 17:00 ET auto-publish if the PR is green. §7.3: this "Weekly Edition" automation is product, not orchestration — it's created BY this item. §8: the intelligence stages are performed by the Devin session inside the automation.

## Scope

- A GitHub workflow (or Devin Automation, whichever fits the §7.3 model — the Weekly Edition is a Devin automation per the plan: choose automation, since classify/draft need a session) that on Saturday 06:00 ET starts a session which: runs deterministic stages (ingest → rank), fills classification/evidence/one_liner/briefing via the session seam per §8, runs verify + validate, and opens the edition PR (`Closes` nothing; label convention documented — propose `edition` label; enable auto-merge).
- Sunday 17:00 ET publish step: if the edition PR is green, it merges via auto-merge (no separate job needed) — the publish = merge to main + Vercel deploy. Document the exact mechanism; a workflow_dispatch manual trigger must exist for dry runs.
- The automation is created via `devin_automation_manage` from within this session if the tooling is available; otherwise ship `.github/workflows/` + instructions and open a `plan-defect` noting the manual step.
- The session prompt for the automation is versioned in the repo (e.g. `plan/weekly-edition-prompt.md`) so it's reviewable.

## Out of scope

- Running a real weekly build (S1 does the first one); retries/alerts (Supervisor's domain).

## Interfaces

- `pnpm edition:build` (I1); the session `llm()` hand-off format (P4); `Closes #N` not applicable — edition PRs are standalone (document).

## Proof

- The automation/workflow exists, is enabled, next-run time shown.
- A manual dispatch dry-run demonstrates the session prompt + stage chain on fixtures.

## Acceptance

- Weekly Saturday 06:00 ET automation exists and produces an edition PR end-to-end on a manual trigger.
- Sunday 17:00 ET publish mechanism documented (auto-merge on green).
- Session prompt versioned in repo.
- No secrets required beyond GITHUB_TOKEN/Devin automation internals.
- `pnpm check` green.
