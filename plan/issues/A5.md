# A5: Adapter — press-wire RSS (funding + M&A filters)

**Wave:** 2 · **Depends on:** C5

## Context

PLAN §5.1: The Money + Deals secondary sources — PR Newswire, Business Wire, GlobeNewswire feeds with "artificial intelligence" + "funding" filters; TechCrunch funding RSS; Axios Pro Rata RSS; Crunchbase News RSS (news only, not the database). FT/Guardian/NYT RSS headlines are corroboration-only.

## Scope

- `packages/pipeline/src/sources/press-wire-rss.ts` implementing the C5 adapter interface.
- Per-wire feed entries in `config/sources.yaml` with the funding/M&A filter strategy documented (keyword filter on headline/summary using taxonomy terms; filters live in config, not code).
- Licence notes per wire (press-release redistribution posture for headline+link+short excerpt).
- Fixtures + harness tests.

## Out of scope

- Amount/stage/lead extraction (P5).

## Interfaces

- C5 `RawItem`; `config/sources.yaml`.

## Proof

- Fixture replay yields filtered RawItems (e.g. only funding-flavoured headlines survive the filter).
- Live smoke run in PR.

## Acceptance

- The §5.1 wire + funding-feed set covered (or gaps documented per feed).
- Funding/M&A filters are config-driven and demonstrated on fixtures.
- Licence notes per source; ≤300-char excerpts; no bodies.
- Deterministic tests; graceful per-feed failure.
- `pnpm check` green.
