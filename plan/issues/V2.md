# V2: Desktop front page renderer

**Wave:** 2 · **Depends on:** C2, C4

## Context

DESIGN §2.2 (the front page — one long newspaper-structured page per issue, locked choice per §7.1), §3 (per-page rules), §5 (no client JS except sticky bar, keyboard nav, chart hydration). Renders a C2-conformant edition JSON on ≥ 768px.

## Scope

- `/{issue}` on ≥ 768px renders the §2.2 layout top→bottom on the 12-col grid: masthead band (wordmark, tagline, date line, Issues + For agents links, 2px rule), cover block (cols 1–8 image 4:5, cols 9–12 headline stack with red `№` kicker), Briefing (cols 3–10, drop-lead first sentence, hairlines above/below), section bands for Models/Performance/Launches/Funding/Deals/Discourse (uppercase Inter Tight 700 head + 2px rule, 3-column rule-separated item grid, ≤6 items), Markets (cols 1–7 chart, 8–12 mono table ticker/close/Δ with --up/--down), Most Covered (5-row boxed table cols 4–9: rank · logo · name · stories · trend), Back page (three columns: Sources mono counts, How this issue was made, For agents links; copyright + licence line).
- Sticky thin top bar: masthead · issue · section links.
- Keyboard nav: `j/k` + arrows jump sections; `?` shows a shortcuts sheet.
- Markets `LineChart` per §1.5 (SVG, 1.5px lines, ink + one tint, mono axis labels).
- No client JS beyond the sticky bar, keyboard nav, and chart hydration — server-rendered otherwise.
- Fixture edition wired in.

## Out of scope

- Mobile deck (V1), per-page routes/OG (V3), archive/brand (V4).

## Interfaces

- Consumes `Edition` from `@weekly/schema` + `@weekly/ui` primitives (`FrontPage`, `SectionHead`, `Item`, `MonoTable`, `TrendDelta`, `LineChart`, `AgentAccess`…).

## Proof

- Full-page screenshots at 1440×900 on the preview, attached to the PR (all sections visible).
- Keyboard nav + `?` sheet demonstrated.
- View-source/lighthouse shows no client JS beyond the allowed islands.

## Acceptance

- `/{issue}` renders the complete §2.2 layout at ≥768px in fixed template order.
- Grid spans match §2.2 exactly (cover 1–8/9–12, briefing 3–10, markets 1–7/8–12, most-covered 4–9 boxed).
- Sticky top bar + `j/k`/arrow section jumping + `?` shortcuts sheet work.
- Client JS limited to sticky bar, keyboard nav, chart hydration.
- Density target: whole issue readable in ~4 minutes of scrolling; no sidebars/feeds.
- `pnpm check` green.
