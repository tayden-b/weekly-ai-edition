# P1: Pipeline — normalize + dedupe stages

**Wave:** 2 · **Depends on:** C5

## Context

PLAN §5.2: `normalize` (canonical URL, publisher, timestamps) → `dedupe` (URL + SimHash on titles; cross-source clusters keep every source link). Consumes `RawItem[]` from adapters; emits the normalized clustered stream every later stage reads.

## Scope

- `packages/pipeline/src/stages/normalize.ts`: canonical URL resolution (tracking-param stripping — utm_*/fbclid/gclid etc., trailing-slash/case normalization, AMP/redirect unwrapping where mechanical), publisher normalization to config names, timestamp normalization to ISO.
- `packages/pipeline/src/stages/dedupe.ts`: exact-URL dedupe + SimHash near-dedupe on titles; produces item clusters where every source link is preserved (cluster → one story, N sources — this shape is what `sources[]` on edition items is built from).
- Stage plumbing consistent with `PIPELINE_STAGES` ordering: pure functions in/out, no I/O inside stages.
- Deterministic unit tests over recorded adapter fixtures (write 2–3 small raw fixtures if needed under `packages/pipeline/testdata/`).

## Out of scope

- Classification/rank/extraction; the ingest orchestrator (P3); LLM use (none — deterministic stages).

## Interfaces

- Input: `RawItem[]` (C5). Output: `NormalizedItem`/`ItemCluster` types you define and export — P2/P4 consume them; keep names stable and documented.
- `sources[]` preservation must round-trip into the C2 `EditionSource` shape.

## Proof

- Fixtures with known duplicates (same story, 2 outlets; same URL, tracking params) cluster correctly and keep all source links in tests.
- SimHash threshold documented + tunable via config.

## Acceptance

- `normalize` produces canonical URL, publisher, ISO timestamps; tracking params stripped — covered by tests.
- `dedupe` merges same-story items across sources into clusters preserving every source link.
- Near-duplicate titles (SimHash) dedupe deterministically; threshold configurable.
- Stages are pure functions — no I/O, fully test-covered on fixtures.
- `pnpm check` green.
