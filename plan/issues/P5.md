# P5: Extraction with evidence spans

**Wave:** 3 · **Depends on:** P4

## Context

PLAN §5.2: `extract` — deterministic regexes + LLM structured extraction for amounts/stages/acquirers, **with the quoted span from the source excerpt required**. §5.3: every number in Money/Deals/Performance/Markets carries `evidence: {source_index, quote}`; CI re-checks the quote exists in the stored excerpt. This is the provenance load-bearing stage.

## Scope

- `packages/pipeline/src/stages/extract.ts`: for classified Funding/Deals/Performance/Markets items, produce structured fields (amount_usd, stage, lead_investor, acquirer, target, metric_name, metric_value, …) — deterministic regexes first, the `llm()` seam (P4's interface) for what regexes can't get, via `prompts/extract.prompt.md`.
- Every extracted field emits `evidence {source_index, quote}` where `quote` is a verbatim substring of that source's stored excerpt — enforced by a hard check in the stage (a field without a contained quote is dropped, and the drop is recorded).
- Replay implementation makes extraction deterministic in tests/CI (recorded responses).
- Tests: fixture items with known amounts → correct extraction; a quote not present in the excerpt → field dropped + flagged (never passes silently).

## Out of scope

- Adapters (raw excerpts arrive via RawItem); the verify gate that re-checks this in CI (P7 — your stage must emit data P7 can verify).

## Interfaces

- `llm()` seam from P4; `EditionItem.evidence` shape from C2 — emit exactly what the schema declares.

## Proof

- Tests show: valid extraction with contained quotes passes; fabricated/mismatched quotes are dropped.
- PR includes a small real-extraction sample (run during the session on fixture raw data) with quotes highlighted.

## Acceptance

- Extract produces structured money/deal/performance/markets fields via regexes + `llm()` seam.
- Every extracted field carries `evidence {source_index, quote}`; quote-in-expert containment enforced in code — violations are dropped and logged, never shipped.
- `prompts/extract.prompt.md` versioned.
- Deterministic replay in tests/CI.
- `pnpm check` green.
